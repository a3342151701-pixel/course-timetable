# 我的课程表

一个面向学生的网页课程表：**自己排课、导入 Excel、每门课自动配色**。
纯前端、无需安装、无需联网，双击 `index.html` 就能用。

**在线版：<https://a3342151701-pixel.github.io/course-timetable/>**（手机、平板、其他电脑直接打开即可，不用装任何东西）

打不开 github.io 的网络（部分校园网、运营商网络）可以试试同一个仓库的镜像地址：
<https://raw.githack.com/a3342151701-pixel/course-timetable/main/index.html>

所有数据（课表、节次设置、配色）都只存在**访问者自己的浏览器**里（localStorage），
不会上传到服务器、不会写回 GitHub，别人打开看到的仍然是仓库里的原版示例课表。

> 同一个仓库里还有一个上课点名用的页面：[随机点名 rollcall.html](rollcall.html)（详见下面「[随机点名](#随机点名rollcallhtml)」）。
> 在线版地址是 <https://a3342151701-pixel.github.io/course-timetable/rollcall.html>，两个页面的数据互相独立。

## 快速开始

1. 双击打开 [index.html](index.html)（推荐 Chrome / Edge），或者直接打开上面的在线版。
2. 第一次打开会自带一份示例课表，可以直接改成自己的；点右上角「更多 → 清空全部课程」就能清空。
3. 想导入现成的教务系统课表，点「导入 Excel」，选文件后确认即可。

如果需要通过 http 访问（某些浏览器对本地文件的限制较严），可以在项目目录下执行：

```bash
node tools/serve.js              # 本机 http://localhost:5173
node tools/serve.js --local      # 只允许本机访问
```

`serve.js` 默认监听 `0.0.0.0`，所以启动后会打印局域网地址（如 `http://192.168.1.5:5173`），
同一 Wi-Fi / 同一校园网下的手机、平板等设备可以直接打开这个地址。
Windows 首次运行会弹出防火墙询问，勾选「专用网络」并允许即可。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 课表视图 | 行＝节次、列＝星期一至星期日，连上两节的课程合并为一个单元格；每两节为一个大节，大节之间画了分隔线；每个星期下面显示这一周对应的具体日期，今天用彩色标出 |
| 日期显示 | 按使用者设备的**本地时间**算出星期一至星期日各自的日期（如 `10/12`），今天会写「今天」；第 1 周周一的日期可以自己填，没填会自动按今天对齐当前周次 |
| 列表视图 | 表格列出全部课程，支持搜索、按星期筛选、按名称或周次排序 |
| 编辑课程 | 点击空白格子新增，点击已有课程修改 / 删除 / 复制到其他星期；课表里选的是「第几大节」，所以每门课都是连着两节 |
| 每门课一种颜色 | 按课程名自动分配背景色，同一门课颜色始终一致；也可以手动指定 |
| 周次与单双周 | 支持 `1-16`、`1-8,10-16`、`1-16单周`、`双周` 等写法；顶部滑块切换当前周次，非本周的课程自动变淡 |
| 冲突提示 | 同一天、节次重叠、周次有交集的课程会标出红色「冲突」 |
| 导入 Excel | 自动识别「网格型」和「列表型」两种表格，导入前可预览、可选择追加或覆盖；表格里只写了半节的课程会自动补成整个大节 |
| 导出 | 当前课表导出为 Excel，或导出模板、导出 JSON 备份 |
| 节次与周次设置 | 每天的节次数量、名称和上下课时间都可以改（可以按大节一次加两节），学期周数和第 1 周周一的日期也可改 |

数据保存在浏览器的 localStorage 里（只在本机、只在这个浏览器中）。
换电脑、换浏览器、清理浏览器数据之前，记得先「更多 → 导出 JSON 备份」。

默认作息（可以在「更多 → 节次与周次设置」里改）：

| 大节 | 节次 | 时间 | 说明 |
| --- | --- | --- | --- |
| 第 1 大节 | 第 1-2 节 | 08:00 - 09:35 | 大节内两节课之间课间 5 分钟 |
| 第 2 大节 | 第 3-4 节 | 09:50 - 11:25 | 与上一大节间隔 15 分钟 |
| 第 3 大节 | 第 5-6 节 | 14:00 - 15:35 | 午休 11:25 - 14:00 |
| 第 4 大节 | 第 7-8 节 | 15:50 - 17:25 | 与上一大节间隔 15 分钟 |
| 第 5 大节 | 第 9-10 节 | 18:00 - 19:35 | 晚上 18:00 开始上课；晚餐休息 17:25 - 18:00 |

每节课 45 分钟，**两节 45 分钟的课算一个大节**：大节内部两节课之间休息 5 分钟，大节与大节之间休息 15 分钟。
全天 08:00 开始（上午 08:00、下午 14:00、晚上 18:00 开始上课），最后一节 19:35 下课。课表里每两节之间画了一条分隔线，方便一眼看出「连着上的两节」。

课程只能按**整大节**安排，不会出现单独一节 45 分钟的课：

- 新增 / 编辑课程时选的是「第几大节」，一门课最少连着两节（跨两个大节的课选「开始大节 2 / 结束大节 3」，就是连着第 3-6 节）。
- 导入的表格里如果只写了半节（例如只写了第 4 节）或者跨了半个大节（例如第 3-5 节），会自动补成整个大节（第 3-4 节 / 第 3-6 节），导入预览里会提示有几条被调整过。
- 「节次与周次设置」里建议保持偶数个节次；如果写成奇数，最后一节不会出现在课表里。

## 每个星期对应的日期

课表顶部「星期一 … 星期日」下面显示的是**当前这一周里各天对应的具体日期**（如 `10/12`），
日期按**使用者设备的本地时间**计算，不联网、不查服务器；今天是哪一天会写成「今天」并用彩色标出，
鼠标停在上面可以看到完整日期（如 `2026-10-12`）。页脚也会显示当前周次的日期范围（如 `第 3 / 16 周（10/26 - 11/1）`）。

日期由「第 1 周周一是哪一天」推算出来，这个值有两种来源：

- **自己填**：更多 → 节次与周次设置 → 「第 1 周周一」，填上学校公布的开学日期（第 1 周的星期一），
  之后每一周的日期就都是准确的学期日历；跨月、跨年（如 12/28 开学、第 3 周到 1 月）也会正常计算。
- **自动推算**：没填过的时候，程序会把「当前周次」对齐到本周，即第 1 周周一 = 本周周一 −（当前周次 − 1）× 7 天，
  并把这个日期存下来（所以以后每周打开时第几周对应的日期不会乱跳）。
  设置里点「按今天自动填」可以随时重新按今天推算一次。

注意：周次本身仍然是手动的（顶部滑块 + 每门课的「上课周次」），程序不会去猜现在是第几周；
如果日期显示和真实学期差了几周，改一下「第 1 周周一」即可。

## 导入 Excel：支持哪些格式

导入时程序会先看工作表的前几行，自动判断是**网格型**还是**列表型**，
识别结果会显示在导入窗口里，如果判断错了可以手动切换，改完立刻重新预览。

### 一、网格型（和纸质课表一样）

第一行是星期表头，第一列是节次：

| 节次 | 时间 | 星期一 | 星期二 | … |
| --- | --- | --- | --- | --- |
| 第1节 | 08:00-08:45 | 高等数学<br>张伟<br>三教201 | 线性代数<br>李娜<br>三教305 | … |
| 第2节 | 08:50-09:35 | ↑（合并单元格） | | … |

识别规则：

- 星期表头支持 `星期一 / 周一 / 礼拜一 / 一 / Mon / Monday`，表头行上方有几行标题也没关系。
- 节次支持 `第1节`、`1`、`1-2节`、`第一节`、`1、2节`；第一列如果是上下课时间（`08:00-08:45`）也不会被误当成节次。
- 连上两节的课程，把上下两行**合并成一个单元格**即可，导入时会自动合成一条。
- 课程按整大节（连着两节）算：只写了一行（例如只有第 4 节）的课程，导入时会自动扩成第 3-4 节，导入预览里会提示有哪几条被调整。
- 单元格内容可以分行写：

  ```
  高等数学
  张伟
  三教201
  1-16单周
  ```

  也支持一行写法：`高等数学@三教201`、`高等数学(三教201)`、`程序设计 王强 机房A302`。
- 分行内容会按规则区分姓名和教室：出现「老师/教师/教授」后缀、或者 `楼/室/馆/场/厅/堂/区/机房/线上/直播` 等词、或者带数字的房间号（`A302`、`教三401`、`文科楼220`）会被识别为教室；2～5 个汉字或英文姓名的会被识别为教师；剩下内容进「备注」。

### 二、列表型（每行一条课程）

第一行是列标题，至少要包含「课程名称」，以及「星期」「节次」中的至少一个：

| 课程名称 | 星期 | 节次 | 周次 | 上课地点 | 任课教师 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 高等数学 | 周一 | 1-2 | 1-16 | 三教201 | 张伟 | 带计算器 |
| 大学英语 | 周一,周五 | 3-4 | 1-16 | 外语楼105 | Linda | 分 A/B 班 |

识别规则：

- 列标题支持常见别名：`课程名/课程/科目/名称`、`老师/教师/任课教师/授课教师`、`教室/地点/上课地点/上课教室`、`节次/上课节次`、`开始节次＋结束节次`、`周次/周数/教学周`、`备注/说明`、`上课时间`。
- 「星期」可以写 `周一`、`星期一`、`1`，多个星期用逗号分隔（`周一,周三`），会拆成多条课程。
- 「节次」可以写 `1-2`、`3、4`、`5`；如果表格分成「开始节次」「结束节次」两列也行。写 `5` 这种单个节次时，导入后会变成整大节（第 5-6 节）。
- 「周次」支持 `1-16`、`1-8,10-16`、`1-16单周`、`1-16双周`、`全部`，留空表示全部周次。
- 缺少星期信息的行会被跳过（并在提示里列出），缺少节次的行会默认填第 1 大节（第 1-2 节）。

### 三、示例与模板

- [samples/](samples) 里有四种示例文件，可以用来试导入：
  `示例-网格型课表.xlsx`（带标题行和合并单元格）、`示例-网格型简版.xlsx`（无时间列、`课程@地点` 写法）、
  `示例-列表型课表.xlsx`（两张表：一列节次 / 开始+结束节次）、`示例-列表型课表.csv`。
  另外 `示例-花名册.xlsx`（序号 / 学号 / 姓名 / 性别，两张表）和 `示例-花名册.csv` 是给随机点名页试导入用的。
- 菜单「更多 → 下载网格型模板 / 下载列表型模板」会下载带示例行和「填写说明」工作表的 xlsx，按这个格式填好再导入最省事。
  （模板里的示例行记得替换成自己的课程。）

## 随机点名（rollcall.html）

仓库里的第二个页面，上课点名用：**先准备一份待点名名单，然后从名单里随机抽若干个名字**。
纯前端、离线可用，双击 [rollcall.html](rollcall.html) 就能用（在线版：
<https://a3342151701-pixel.github.io/course-timetable/rollcall.html>），课表页「更多 → 随机点名」也能打开它。

| 功能 | 说明 |
| --- | --- |
| 手动添加名单 | 单个添加：输入姓名回车；批量添加：把名字粘贴进文本框，每行一个，也支持逗号、顿号、空格分隔（可以直接从 Excel 里复制一列粘进来），填好后选「追加到名单」或「替换整个名单」 |
| 导入花名册文件 | 支持 `.xlsx` / `.xls` / `.xlsm` / `.csv` / `.txt`。自动判断「姓名」在哪一列（表头写 `姓名`、`名字`、`学生`、`Name` 等都认得；找不到表头时按「哪一列最像人名」来猜），也可以手动换列，或者选「整张表」把多列名单（例如分组名单）一次全取出来；导入前会预览解析出的名字，并提示跳过/去重了多少项 |
| 随机抽取 | 抽取人数可以直接填，也有 1 / 2 / 3 / 5 / 剩余全部 的快捷按钮；一次抽取里不会抽到同一个人；开着「本轮不重复」时，抽过的人不再参与，直到点「重置本轮」 |
| 结果 | 被点到的名字按抽取顺序显示成大卡片，可以一键复制；抽取时名字会滚动一下（不想要滚动可以在选项里关掉） |
| 抽取记录 | 每次抽取都会记一条（时间、抽到的名字、当时候选人数），可以复制某一条，也可以导出成 txt |
| 名单管理 | 名单以名字标签显示：点名字可以切换「本轮已抽」标记（有人请假时用得上），点名字右边的 × 删除；「更多」里可以导出名单、重置本轮、清空记录、清空整个名单 |

几个实现上的说明：

- 随机数优先用 `crypto.getRandomValues`（浏览器自带），并用拒绝采样去掉取模偏差，保证每个人被抽到的概率一样；不支持时才退回 `Math.random`。
- 导入花名册时会自动跳过学号、序号、性别、表头、合计行等明显不是姓名的内容，学号写在姓名同一格（如 `2026001 张三`）也能认出来；名字前面的序号（`1.` `1、` `1 `）会被去掉。
- 名单、本轮已抽状态、抽取记录都只存在浏览器本地（localStorage，键 `roll-call/v1`），和课表数据互不影响，也不会上传服务器。

## 导出与备份

- **导出 Excel**：把当前课表导出成网格型 xlsx。导出的文件可以直接再导入回来。

同一份文件还可以通过只读镜像访问（github.io 被运营商或校园网挡住时用）：

| 地址 | 说明 |
| --- | --- |

注意：jsDelivr、Statically 这类 CDN 会把 `.html` 当作 `text/plain` 返回（浏览器直接显示源码），

写入方向只有一个：**本地 → GitHub**。网页是纯静态前端，代码里没有任何 `fetch` / `XMLHttpRequest`，
运行时既不调用 GitHub API，也不会把数据写回仓库；每个访问者的课表都存在自己浏览器的 localStorage 里，
刷新、换设备、清空缓存都只影响他自己，GitHub 上的原版（`main` 分支）始终不变。

## 已知限制

- 数据只存在当前浏览器的本地存储里，不联网、不跨设备同步；换设备请用 JSON 备份。
- 「现在是第几周」由你自己用顶部滑块（和「第 1 周周一」的日期）决定，程序不会自动判断今天属于第几周。
- 课程按整大节安排，不能只排单独一节 45 分钟的课；如果学校有单节的课，请把它当作一个大节来排。
- 一个时间格里出现两门课（真正的排课冲突）时，导出的 Excel 会把两门课写在同一格，网页里则会显示「冲突」标记。
- 导出 Excel 不带颜色（原因见上）。
- 点名名单按姓名去重，所以**同名的两个人只能算一个**（导入花名册时会提示去掉了几个重名）；班里有同名学生时，可以在名字后面自己加个标记（如 `张三（1 班）`）。
- 点名页不含「按学号顺序」「按小组轮换」这类规则，每次都是从当前候选池里等概率随机抽；名单和抽取记录存在浏览器里独立的位置（键 `roll-call/v1`），和课表数据互不影响。
